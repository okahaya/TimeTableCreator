# TimeTable Creator

**TimeTable Creator** は、音楽フェスやライブイベントなどのステージ進行表（タイムテーブル）を効率的に作成するためのアプリケーションです。
出演団体の希望時間やステージ数を入力するだけで、条件を満たす最適なスケジュールを自動生成します。


## 主な機能

### 1. 柔軟なイベント設定

- **複数日程対応**: 最大10日間のイベントに対応。
- **マルチステージ**: メインステージ、サブステージなど複数のステージを管理可能。
- **時間設定**: ステージごとに開始・終了時間を設定可能。
- **時間短縮の自動調整**: スケジュールが過密な場合、自動的に持ち時間を短縮して枠に収める機能を搭載。

### 2. 多彩なデータ入力

- **CSVインポート**: Excelなどで管理している団体リストを一括読み込み（テンプレートあり）。
- **手動入力**: GUIで直感的に団体を追加・編集可能。
- **デモデータ**: 動作確認用のランダムデータをワンクリックで生成。

### 3. 高度な自動最適化

- **Web Workerによる並列処理**: ブラウザをフリーズさせることなく、バックグラウンドで高速計算。
- **Simulated Annealing (焼きなまし法)**: 制約条件（希望時間、重複禁止など）を満たしつつ、全体の満足度が最大になる解を探索。
- **自動調整**: 解が見つからない場合、短縮率を自動で調整して提案。

### 4. 直感的なタイムライン調整

- **ドラッグ&ドロップ**: 帯をドラッグして時間を移動、端をドラッグして持ち時間を変更。
- **視覚的なフィードバック**:
  - 🟢 **緑**: 希望通り（または希望範囲内）
  - 🟡 **黄**: 希望からズレあり / ドラッグ中の重複
  - 🔴 **赤**: 希望外 / 重複（禁止）
  - **ゴースト表示**: ドラッグ中に本来の希望位置をうっすら表示。
- **Undo/Redo**: `Ctrl+Z`, `Ctrl+Y` で操作の取り消し・やり直しが可能。

### 5. 出力・連携

- **CSVエクスポート**: 確定したタイムテーブルをCSV形式で保存。

## 🛠 技術スタック

- **Frontend**: React, TypeScript
- **Styling**: Tailwind CSS, Lucide React (Icons)
- **Runtime**: Vite, Electron
- **Algorithm**: Simulated Annealing (Client-side Web Workers)

## 💻 開発環境セットアップ

### 必要要件

- Node.js
- npm

### インストール

```bash
# リポジトリのクローン
git clone <repository-url>
cd TimeTableCreator

# 依存関係のインストール
npm install
```

### 開発・実行

**Webブラウザで開発:**

```bash
npm run dev
```

**Electronアプリとして起動:**

```bash
npm run electron:dev
```

**ビルド (Windows用インストーラー作成):**

```bash
npm run dist
```

`release/` ディレクトリにインストーラー（.exe）が生成されます。

## 📖 使い方フロー

1. **基本設定**: イベントの日数、時間、ステージ数を設定します。
2. **データ入力**: 出演団体と希望時間を登録します。CSVインポートが便利です。
3. **自動作成**: 「作成スタート」ボタンを押すと、数秒〜数十秒で最適化が行われます。
4. **微調整**: 生成されたタイムラインをドラッグ&ドロップで微調整します。
5. **出力**: 完成したらCSVで保存します。

## 🧩 最適化ロジックについて

本アプリは **焼きなまし法 (Simulated Annealing)** を採用しています。

- **コスト関数**:
  - 希望時間とのズレ（分単位のペナルティ）
  - 割り当てなし（最大のペナルティ）
  - 時間重複（禁止制約）
  - 団体間の公平性（分散）
- 上記のコストが最小になるように、数千〜数万回の反復計算を行い、最適な配置を決定します。
